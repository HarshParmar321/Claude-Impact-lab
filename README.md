# NagarLens

**Evidence-to-action accountability for Mumbai road repairs.**
*Find the evidence. Hear both sides. Act on every rupee.*

NagarLens connects citizen complaints, work orders, roads, contractors, rate cards, wards, repair outcomes and public-risk data. It produces deduplicated audit **review leads**, fair contractor and ward scorecards, and budget-capped recommendations for where the next rupee should go.

The **RupeeProof Action Layer** turns each review lead into a decision a ward officer and a citizen can act on:

```text
Review lead → Claude Fair Hearing → Release Payment | Hold for Evidence | Warranty Review
           → Public Repair Receipt → “Did this repair survive?” → failed repair returns to warranty review
```

NagarLens never declares fraud. It uses *review lead*, *record conflict*, *supporting evidence required* and *warranty verification required*.

## Run it locally

Requirements: Python 3.10+ and Node.js 20+.

### Backend (http://localhost:8000)

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000
```

### Frontend (http://localhost:3000)

```bash
cd frontend
npm install
cp .env.local.example .env.local
npm run dev
```

Open:

```text
Frontend:     http://localhost:3000
Backend docs: http://localhost:8000/docs
```

### Claude (optional)

The demo works **without an Anthropic API key**. The Fair Hearing falls back in this order:

1. **live**: the backend calls Claude with the Anthropic Python SDK (only if `ANTHROPIC_API_KEY` is set in `backend/.env`).
2. **cache**: `backend/cache/claude_responses.json`, keyed by a SHA-256 hash of the structured evidence. It ships with responses for the golden cases (WO25-02469, WO25-01483, WO25-02270). These were pre-generated by Claude during the build and are labelled as such.
3. **template**: a deterministic hearing assembled from the audit rules.

A Claude Max subscription does not include API credits; live calls need an API key with API access. Set `ANTHROPIC_MODEL` to any current Claude model ID. To refresh the golden cache with live responses: `python scripts/build_golden_cache.py --live`.

The browser never calls Anthropic. The API key stays in the backend.

```bash
cd backend && pytest -q
```

1. **Overview**: NagarLens connects the full money trail.
2. **Reviews** → open **WO25-02469** (pinned demo case).
3. Show the English and Marathi complaints, the category conflict, and the matching earlier order WO25-01483.

6. Accept **Warranty Review** and the evidence checklist (an override needs a written reason).

## Audit rules (deterministic, in Python)

| Rule | Definition |
|---|---|
| Expected cost | `area_sqm × standard_rate` (per sqm) or `standard_rate` (per job); `ratio = actual ÷ expected` |
| Rate bands | `<0.75×` data-quality outlier (not overbilling) · `0.75–1.30×` normal · `>1.30–1.40×` context band (shown, not counted) · `>1.40×` **rate-card review lead** |
| Possible duplicate | no linked complaint · same road, work type and method · area within 5% · completed ≤ 4 days apart · cost within 6% |
| DLP review | road under DLP and BMC billed > ₹0 → Ward Warranty Desk; not attributed to the current contractor |
| Counting | a work order caught by several rules is **one** lead; rule hits are shown separately and never summed |
| Verdict precedence | DLP → Warranty Review; else duplicate or rate lead → Hold for Evidence; else → Release Payment |

Claude explains results. It does not calculate them.

## Data

`backend/data/` holds a **synthetic** dataset (every contractor, complaint, amount and accident is fictional; road and ward names are geographic labels only). Regenerate it with:

```bash
cd backend && python scripts/generate_seed_data.py && python scripts/build_golden_cache.py
```

To use the official hackathon dataset, replace the CSV/GeoJSON files in `backend/data/` with the same file names and columns. If an existing, validated calculation module is available (e.g. Kshitij's pandas modules), wire it in through `backend/app/services/*_adapter.py`; the API depends only on the adapters. After swapping data, rebuild the golden cache (the evidence hashes change).

## Security

- `.env` files and SQLite databases are git-ignored. Never commit a real key.
- If a key is ever pushed, **revoke it immediately**. Deleting it in a later commit is not enough, because it stays in Git history.
